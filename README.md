# 和弦地图 · 钢琴练习室

**在线练习：[打开钢琴版和弦地图](https://analalaa.github.io/chord-piano/)**

参考 [Chord Map 吉他版](https://github.com/Analalaa/chord-map)，将和弦构成、转位与跟练重新组织为钢琴实践。纯静态页面，无需账号或外部音源。

## 可以做什么

- 选择12个根音、32种和弦，对照正确拼写的音名与音程度数。
- 比较完整构成与双手实用排列，清楚看到左右手、最低音和省略音。
- 在实际琴键上检查原位与转位，试听齐奏、分解和弦和单音。
- 用A/B对照听大/小三、maj7/7、sus/add9等区别。
- 跟随大调、小调ii–V–I、挂留与增和弦经过连接；每四拍换一次和弦。
- 完成六组课程、20个步骤，用点键答题检查缺音、多选音，配合实体钢琴与节拍器练习。

练习进度只存于当前浏览器。答题检查音级；八度、手型与节奏请结合页面说明在实体琴上练习。声音为合成示范，并非钢琴录音。

## 本机使用

需要 Node.js 20 或更新版本，无第三方依赖。

```sh
npm run dev
npm test
npm run build
```

本机预览默认地址为 `http://127.0.0.1:8779/`。也可直接打开 `piano-chord-map-offline.html`；这是包含全部样式与脚本的离线单文件。

## 发布

推送 `main` 后，`.github/workflows/pages.yml` 会先检查和弦构成与练习材料，再把 `dist/` 发布到 GitHub Pages。仓库 Pages 构建来源设为 GitHub Actions。

## 内容

`dist/music.js` 管理和弦、音名与实际排列；`dist/lessons.js` 管理对比、进行、课程与来源；`dist/app.js` 负责键盘、合成音、答题与跟练。理论完整音集和实际弹奏音分别展示。转位由最低音决定；sus不含三音；m13并非普遍禁用和弦。
